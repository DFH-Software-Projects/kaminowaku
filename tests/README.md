# TUI regression suite

Run from the Kaminowaku repository root on Linux or FreeBSD:

```sh
sh tests/run-tui-regressions.sh
sh tests/run-tui-regressions.sh --bench
```

The single runner compiles permanent C regressions in a temporary directory,
runs them and removes the binaries automatically. Set `SANITIZE=1` to request
AddressSanitizer/UndefinedBehaviorSanitizer when the compiler supports them.
The optional benchmark checks 1,000 unchanged/changed virtual-screen frames,
cached wrapping over the configured 16,384-line scrollback, and ring eviction.
Timing figures are diagnostic, not release pass/fail thresholds.

Coverage includes fragmented SGR/X10 wheel reports, adjacent wheel coalescing,
arrow/editing escapes, interrupted sequences, bracketed multiline paste,
unread bytes after Enter, FIFO event ordering, compositor diffing, ring-buffer
indexing, concurrent event delivery, renderer shutdown/restart and PTY
fork/exec, resize, terminal-state restoration and byte-perfect raw evidence.

**Interactive acceptance is still required:** these checks do not replace a
real terminal session with the full Kaminowaku application. On Linux and
FreeBSD, verify rapid trackpad scrolling mixed with typing, resizing across
the minimum terminal size while scrolled back, both `ui` display modes,
long-running project scans, repeated interactive tools, tool interruption
and shell restoration after quitting. Run the Linux deployment script only
after confirming the branch's dependencies and build prerequisites.

No project source or documentation is generated by this test suite.
