# Licensed NOSIX ABI

This is the existing proprietary NOSIX **binary ABI**, relocated from
the old top-level `nosix_abi/` folder without modifying the bytes or
publishing any NOSIX private source. Both shipped platforms target amd64.

`include/` contains nosix.h, nosix_poll.h and nosix_datagram.h.
`linux/` and `freebsd/` contain their respective abi.env and
lib/libnosix.so.1.4.0. Keep LICENSE and BUILD-MANIFEST.txt alongside
both native binary builds.

Install.sh installs NOSIX to the private `PREFIX/lib/kaminowaku/` path.
Its SONAME and linker symlinks are regenerated by staging to remain
compatible with Windows-hosted release assembly. Never copy the NOSIX
source tree into the public Kaminowaku repository.
